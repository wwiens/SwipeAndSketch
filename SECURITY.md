# Security

Please report vulnerabilities privately through GitHub: on this repository's **Security** tab, choose **Report a vulnerability**. Don't open a public issue for them.

Include the iPad model, the iPadOS version, the app version, and the steps to reproduce. If a file triggers the problem, attach it.

Swipe & Sketch opens files from other people: `.swipesketch` projects and STEP (`.step`, `.stp`) files, which go through the Open CASCADE STEP reader. Crashes, hangs, or runaway memory use from a crafted file are in scope and welcome. So are problems with the assistant changing a model in ways you didn't approve.

Problems in Open CASCADE itself should also go to its maintainers: https://github.com/Open-Cascade-SAS/OCCT.
